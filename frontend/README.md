# Frontend

This directory is reserved for the frontend application.

No frontend application has been imported by this repository-reorganization task.
Frontend code should later be added as a separate workspace package.

## Getting Started

When adding a frontend:

1. Initialize a new workspace package (e.g., React, Next.js, or Vue)
2. Add it to the root `pnpm-workspace.yaml`
3. Use the shared `pnpm-lock.yaml` for dependency management
4. Reference backend APIs via the service URLs in `.env`
